# Takeaway Fighter (v2)

Food fighters settle what's for takeaway tonight. Android-installable web app.

- `index.html`, `game.js`: the app. Published privately as a Claude artifact for testing.
- `manifest.webmanifest`, `sw.js`, `icons/`: make it installable ("Add to home screen") and work offline.
- `./build-site.sh` makes `site/`, a standalone copy to upload to a website (for example
  itsdone.nz/takeaway). It must be served over https for install and offline to work.

The rig: Star of India butter chicken is the champ, the block of butter backs it up, Chada Thai's prawn
can take it, the actual chicken joins the butter (butter + chicken = butter chicken), broccoli is a rare cook-at-home upset, and KFC and McDonald's never win, by KO or on points.
