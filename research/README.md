# NZ road marking rule book (research draft)

`nz-marking-rules.json`: 84 rules, each with its source and a confidence
(confirmed / single-source / unclear). `nz-marking-quiz.json`: 42 quiz questions
built only from confirmed or single-source rules.

NZTA's website blocks automated reading, so NZTA rules come from search-result
summaries of the TCD Manual, MOTSAM, P/22, CoPTTM and related pages, not from the
documents themselves. Check against the crew's own copies before relying on them.
